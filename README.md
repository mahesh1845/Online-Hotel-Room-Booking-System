# Online-Hotel-Room-Booking-System
🏨 Hotel Booking System – Frontend

A responsive Hotel Booking System frontend project developed using HTML, CSS, and JavaScript. This project provides a simple and attractive interface for users to explore hotels, view rooms, and make a hotel booking.

🚀 Features

- 🏨 Attractive hotel homepage
- 🔍 Search hotels
- 🛏️ View room details
- 📅 Select check-in and check-out dates
- 👥 Select number of guests
- 📝 Hotel booking form
- ✅ Booking confirmation
- 📱 Responsive design
- 🎨 Modern and user-friendly interface

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – User interaction and booking functionality

▶️ How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Right-click on "index.html".
5. Select Open with Live Server.

The website will open in your browser.

🌐 Pages

🏠 Home Page

Displays:

- Hotel information
- Search section
- Available hotels
- Navigation menu

🛏️ Booking Page

Allows users to:

- Select hotel
- Select room
- Enter guest details
- Choose dates
- Submit booking

✅ Confirmation Page

Displays the booking confirmation after submitting the booking form.

🎯 Project Objective

The main objective of this project is to create a simple, attractive, and responsive hotel booking website frontend using basic web development technologies.
